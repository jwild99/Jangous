I want to push Jango into a TRUE AAA GAME EXPERIENCE. This is no longer just UI polish — this is about creating emotion, excitement, and addictive gameplay feel.

Everything must feel like:
- A real game (not a website)
- Cinematic
- Responsive
- Rewarding

-----------------------------------
CORE DESIGN PRINCIPLE
-----------------------------------

Every action should:
- Feel impactful
- Trigger feedback (visual + sound)
- Create excitement

Nothing should feel flat or instant.

-----------------------------------
PART 1: MATCH START EXPERIENCE (VERY IMPORTANT)
-----------------------------------

When a user clicks PLAY:

DO NOT instantly start the game.

Create a cinematic match intro.

-----------------------------------
FLOW:
-----------------------------------

1. Screen slightly dims
2. Game logo appears center screen
3. Opponent found (if multiplayer)
4. VS screen appears:

Player 1 vs Player 2

- Avatars displayed
- Subtle glow around both players
- Background animation continues

5. Countdown:

3 → 2 → 1

Each number:
- Scales up
- Glow pulse
- Sound effect

6. Transition into game:
- Quick zoom + fade
- Smooth entry

-----------------------------------
GOAL:
-----------------------------------

Make starting a match feel IMPORTANT.

-----------------------------------
PART 2: WIN / LOSS CINEMATIC
-----------------------------------

After a match ends:

-----------------------------------
WIN:
-----------------------------------

- Screen glow (gold or rarity-based)
- Text appears:

“VICTORY”

- XP + rewards animate in
- Sound plays (reward sound)
- Subtle particle burst

-----------------------------------
LOSS:
-----------------------------------

- Dimmed screen
- Text:

“DEFEAT”

- Softer animation
- No harsh effects

-----------------------------------
GOAL:
-----------------------------------

Even losing should feel clean, not frustrating.

-----------------------------------
PART 3: RANK UP SYSTEM (HIGH IMPACT)
-----------------------------------

When player ranks up:

-----------------------------------
ANIMATION:
-----------------------------------

- Screen darkens slightly
- Rank badge appears center
- Glow builds up
- Burst effect
- Text:

“RANK UP”

- Sound plays (big moment)

-----------------------------------
GOAL:
-----------------------------------

This should feel like a BIG achievement.

SECTION 1: ECONOMY SYSTEM (FULL IMPLEMENTATION)
==================================================

DATA MODEL:

User:
- balance
- sessionStartBalance
- todayStartBalance
- weeklyStartBalance
- totalWinnings
- totalLosses
- winStreak
- lossStreak

Transaction:
- id
- userId
- type (win, loss, deposit, withdrawal, entry_fee, shop_purchase)
- amount
- game
- opponent
- timestamp
- status

FRONTEND COMPONENTS:

1. BALANCE DISPLAY
- always visible in navbar
- format: "12.50 SCALPS"
- animate changes:
  increase:
    - green glow
    - count up (300–600ms)
  decrease:
    - red/orange glow
    - count down

2. FLOATING TRANSACTION FEEDBACK
- appears near balance or center screen
- example:
  "+5 SCALPS"
  "-2 SCALPS"
- fades out after 800ms
- slight upward movement

3. SESSION PANEL (dashboard)
SHOW:
- session P/L
- today P/L
- weekly P/L
- best win
- current streak

CALCULATIONS:
session P/L = currentBalance - sessionStartBalance
today P/L = currentBalance - todayStartBalance
weekly P/L = currentBalance - weeklyStartBalance

VISUAL:
- positive = green
- negative = red

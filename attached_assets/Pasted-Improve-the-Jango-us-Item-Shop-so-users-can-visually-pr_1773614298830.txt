Improve the Jango.us Item Shop so users can visually preview cosmetic equipment items before purchasing, but they cannot use them in a playable demo.

The preview should allow users to look at the item from different angles and see its visual effects, but no gameplay interaction should occur.

Everything must work on mobile and desktop.

---

# ITEM SHOP PREVIEW SYSTEM

Each item card must include:

• Item Name  
• Item Type  
• Rarity  
• Price in Scalps  
• Short Description  
• Preview Button  
• Buy Button  

When users click Preview, a preview window opens showing the cosmetic item in a 3D viewer.

---

# 3D PREVIEW VIEWER

The preview window should allow users to:

• Rotate the item  
• Zoom in and out  
• See lighting reflections  
• View animated cosmetic effects  

Users should not be able to use the item in a game.

Example previews:

Ping Pong Paddle Preview
• Paddle slowly rotates on screen  
• Glow or flame animations play  
• Lighting highlights textures

Pool Cue Preview
• Cue rotates horizontally  
• Shine effects reflect light  
• Small idle animation plays

The preview should look like a showroom display.

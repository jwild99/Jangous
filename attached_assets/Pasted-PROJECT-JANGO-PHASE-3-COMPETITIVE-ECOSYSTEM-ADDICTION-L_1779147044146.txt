==================================================
SECTION 1: TRUE COMPETITIVE SYSTEM (MMR + RANKING)
==================================================

GOAL:
Make players care about winning, improving, and ranking up.

--------------------------------------------------
1.1 MMR SYSTEM (PER GAME)
--------------------------------------------------

Each game must have its own hidden rating:
- chessMMR
- miniGolfMMR
- tronMMR
- etc.

Store:
user_game_stats table:
- user_id
- game_id
- mmr
- wins
- losses
- streak
- last_played

Initial MMR:
- 1000 baseline

MMR formula (ELO-based):

expectedScore = 1 / (1 + 10^((opponentMMR - playerMMR)/400))

mmrChange = K * (actualScore - expectedScore)

Where:
- win = 1
- loss = 0
- draw = 0.5
- K = 32 (default)

--------------------------------------------------
1.2 BONUS SYSTEM (MAKE IT FEEL GOOD)
--------------------------------------------------

Add modifiers:

Upset Bonus:
If playerMMR < opponentMMR:
+10 to +50 extra MMR depending on gap

Close Loss Protection:
If loss is within small margin:
reduce loss by 30–50%

Win Streak Multiplier:
2 wins → +5%
3 wins → +10%
5 wins → +20%

Loss Streak Dampener:
3 losses → -20% penalty reduction

--------------------------------------------------
1.3 RANK TIERS (VISIBLE)
--------------------------------------------------

Map MMR to rank tiers:

Bronze: 0–999  
Silver: 1000–1399  
Gold: 1400–1799  
Platinum: 1800–2199  
Diamond: 2200–2599  
Champion: 2600–2999  
GOAT: 3000+

Each tier must have:
- unique color
- badge icon
- glow style

--------------------------------------------------
1.4 POST MATCH FEEDBACK
--------------------------------------------------

After match show:

+32 MMR
+12 Upset Bonus
Win Streak x3

OR

-18 MMR
Close Match Protection (-40%)

Animation:
- numbers tick up/down
- glow effect based on gain/loss

--------------------------------------------------
1.5 RANK DECAY
--------------------------------------------------

If inactive 7+ days:
- small MMR decay per day

Display:
“Inactive — rating decaying”

--------------------------------------------------
1.6 SEASONS
--------------------------------------------------

Every 90 days:
- soft reset MMR
- keep rank badge history

Add:
Season 1, Season 2, etc.

Leaderboard shows:
- current season
- past champions

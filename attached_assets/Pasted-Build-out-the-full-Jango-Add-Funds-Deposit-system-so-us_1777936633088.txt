CRYPTO FLOW:
For Bitcoin, Ethereum, Solana, and USDC:
1. User selects crypto type
2. User enters deposit amount in USD
3. App shows:
   - Network name
   - Estimated crypto amount
   - USD value
   - Processing fee
   - Final amount credited
4. User clicks Generate Deposit Address
5. Backend checks:
   - User is logged in
   - User email is verified
   - User is eligible to deposit
   - Deposit amount is within min/max limits
   - User passed any required KYC/compliance checks
6. Backend requests a real deposit address from the payment provider
7. Frontend displays:
   - Deposit address
   - QR code
   - Copy address button
   - Crypto amount
   - Expiration timer if applicable
   - Network warning, like:
     “Only send BTC on the Bitcoin network. Sending the wrong asset may result in permanent loss.”
8. Create a pending deposit record in the database
9. Track deposit status:
   - Pending
   - Waiting for blockchain confirmation
   - Confirmed
   - Failed
   - Expired
10. Balance only updates after payment confirmation from the provider/blockchain webhook

DO NOT instantly credit the user just because they generated a deposit address.

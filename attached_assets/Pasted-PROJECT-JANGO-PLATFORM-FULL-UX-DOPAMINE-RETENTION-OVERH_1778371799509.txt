PROJECT: JANGO PLATFORM – FULL UX/DOPAMINE/RETENTION OVERHAUL (EXTENSION)

GOAL:
Upgrade ALL core user-facing pages to:
- Increase engagement
- Increase retention
- Increase session time
- Increase deposits
- Increase competitive behavior

This is NOT a visual tweak.
This is a behavioral upgrade.

==================================================
GLOBAL DESIGN PRINCIPLES (APPLY EVERYWHERE)
==================================================

1. EVERYTHING MUST RESPOND
- hover = lift + glow
- click = scale + feedback
- success = animation
- failure = visual feedback

2. NOTHING SHOULD FEEL STATIC
- numbers count up
- cards subtly float
- glow pulses on important elements
- transitions between states

3. ALWAYS SHOW PROGRESSION
- XP bars
- rank movement
- earnings growth
- streaks

4. ALWAYS CREATE URGENCY
- timers
- limited slots
- “ending soon”
- “only X left”

5. ALWAYS CREATE EMOTION
- wins feel like wins
- losses feel like losses
- deposits feel exciting
- rank gains feel addictive

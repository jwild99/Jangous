BOT SYSTEM REQUIREMENTS
================================

Standardize bot architecture across games.

Need:
- one clean bot difficulty model across the platform
- difficulty selection passed correctly into each game
- no fake difficulty labels where all 3 play the same
- no broken matchmaking / setup logic
- no bot spawn failures
- no “bot selected but nothing happens”

Each difficulty should feel different:

EASY
- slower decisions
- more mistakes
- more forgiving
- weaker accuracy / weaker strategy
- beginner-friendly

MEDIUM
- balanced
- competent
- fewer mistakes
- decent challenge for average players

HARD
- strongest available bot behavior
- smarter decisions
- fewer wasted moves
- harder reaction / planning / aim depending on the game
- should feel competitive, not broken-cheating

Do NOT make hard just unfair input reading or fake cheating.
Make it feel stronger because it plays better.

================================
PER-GAME BOT EXPECTATIONS
================================

Each game should express difficulty in the correct way.

POOL
- Easy bot: weak shot selection, less accurate aim, basic target logic
- Medium bot: decent shot selection, moderate accuracy, smarter power usage
- Hard bot: strong target choice, better angle selection, cleaner power control, fewer bad shots

CHESS
- Easy: simpler shallow move selection
- Medium: stronger tactics
- Hard: strongest search/evaluation available within performance limits

CONNECT FOUR
- Easy: mistakes and shallow lookahead
- Medium: decent blocking and setup
- Hard: strong lookahead and punishes mistakes

AIR HOCKEY
- Easy: slower reaction, less accurate defense/offense
- Medium: balanced
- Hard: quick positioning, smarter rebounds, better defense

MINI GOLF
- Easy: less precise angles/power
- Medium: decent shot planning
- Hard: more accurate line and power choice

DOTS AND BOXES
- Easy: random/suboptimal line choices
- Medium: basic strategy
- Hard: stronger chain control and trap avoidance

ROCK PAPER SCISSORS or simple games
- If bot exists, difficulty can be implemented through pattern reading / reaction logic / adaptive behavior
- Hard should feel smarter, not just random every time

If any game needs custom difficulty logic, build it.

PROJECT: JANGO TUTORIAL MODE 2.0 — FULL INTERACTIVE ONBOARDING + GAME TRAINING SYSTEM

GOAL:
Build a full tutorial system that teaches new users how Jango works and how to play every game, while making the experience feel fun, polished, rewarding, and high-energy.

This should NOT feel like a boring help page.

It should feel like:
- a guided game campaign
- an interactive onboarding experience
- a first mission inside the Jango Arena
- a training ground that gets users excited to play for real

The tutorial must teach:
1. What Jango is
2. What Scalps are
3. How matches work
4. How stakes/pots work
5. How tournaments work
6. How ranks/progression work
7. How to play each individual game
8. How to safely practice before playing real matches

IMPORTANT:
Do NOT give away free Scalps as tutorial rewards.
Tutorial rewards should be cosmetic, XP-based, badge-based, or progression-based only.

==================================================
SECTION 1: CORE TUTORIAL DESIGN PHILOSOPHY
==================================================

The tutorial must follow this loop:

TEACH → MAKE USER DO IT → GIVE FEEDBACK → REWARD → MOVE FORWARD

Do not explain everything with text.

Every step should include:
- a visual highlight
- a short instruction
- an action the user performs
- instant feedback when completed
- a progress checkmark
- sound/haptic if enabled

Bad tutorial style:
“Here is a paragraph explaining everything.”

Good tutorial style:
“Click Play.”
User clicks Play.
Button glows.
Sound plays.
Step completes.
Progress bar moves.

SECTION 24: BOT BEHAVIOR DURING TUTORIALS
==================================================

Tutorial bots should be scripted, not fully competitive.

Rules:
- bot should help teach
- bot should not crush the user
- bot should make controlled mistakes
- bot should pause long enough for explanation
- bot should never freeze

First tutorial win should be highly likely.

Bot difficulty:
Tutorial bot = easier than Easy.

==================================================
SECTION 29: ERROR HANDLING
==================================================

Tutorial must never trap the user.

If step breaks:
- show:
  “Something went wrong with this step.”
- buttons:
  Retry Step
  Skip Step
  Exit Tutorial

If game fails to load:
- show fallback instruction card
- allow return to Tutorial Hub

If user refreshes:
- resume at last saved step

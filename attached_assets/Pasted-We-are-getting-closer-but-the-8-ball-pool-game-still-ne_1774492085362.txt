We are getting closer, but the 8-ball pool game still needs a stronger polish and gameplay pass. The current version is a step up, but it still does not feel premium, realistic, or satisfying enough. It needs more dopamine, better feedback, more realistic table art, larger/more accurate pockets, and the shot release mechanic still is not functioning correctly. Right now, dragging back and releasing is not consistently translating into an actual cue strike / cue ball motion. That must be fixed.

THIS NEXT PASS SHOULD FOCUS ON 5 THINGS:
1. Make the table look more realistic and premium
2. Add more satisfying visual/game feedback (“dopamine”)
3. Fix shot release so drag-back and release always shoots correctly
4. Make pockets feel more like a real pool table
5. Improve game-state feedback for scratches, 8-ball mistakes, and pocketed balls

PRIORITY #1 — FIX THE DRAG-AND-RELEASE SHOT
This is still the biggest gameplay issue.

Current problem:
- aiming works
- dragging back for power looks better
- but releasing does not reliably strike the cue ball
- sometimes the cue animation does not actually translate into a shot
- the ball needs to clearly launch when I release

Fix this properly:
- on pointer/touch drag start: begin charge state
- on drag back: update power continuously and visually
- on release: ALWAYS convert the stored shot vector + power into a cue strike impulse
- do not lose shot state because of event ordering issues
- make sure pointerup / mouseup / touchend all route into the same fireShot() logic
- ensure the cue ball velocity is applied immediately on release
- prevent release events from being swallowed by overlay/UI layers
- prevent stale state / async state timing bugs
- log the following during testing:
  - drag started
  - charge amount
  - release detected
  - shot impulse applied
  - cue ball velocity after shot

Technical requirement:
- there should be one clear, central shot release function
- desktop mouse release and mobile touch release should both call the same reliable shot execution path
- no fake animation without real physics impulse
- no release state where the cue animates but the ball does not move

Acceptance test:
- click/touch drag back
- release
- cue ball moves every single time

- more realistic pocket cutouts
- darker pocket interiors with depth

Design target:

Do not overdo texture noise.
Keep it clean, readable, and premium.

PRIORITY #3 — POCKETS / HOLES NEED TO LOOK AND FEEL RIGHT
The pockets especially the corner pockets feel too small and not quite right visually.

Update pockets:
- enlarge and reshape corner pockets so they feel closer to a real table
- improve side pocket shape too
- pocket openings should visually read clearly
- pocket mouths should feel more forgiving and natural
- balls should drop in more satisfyingly
- improve collision/pocket funneling near the openings

Important:

- visual size and gameplay detection need to match
- pocketing should feel fair and satisfying

PRIORITY #4 — ADD MORE DOPAMINE / FEEDBACK
The game needs more “something happened” energy. Pocketing a ball should feel rewarding. Fouls and big moments should feel noticeable.

Add satisfying feedback for key events:

WHEN A BALL IS POCKETED:
- quick popup text like:
  - “Nice Shot”
  - “Ball Sunk”
  - “Clean Pocket”
- subtle score/event banner
- pocket flash or pulse near the hole
- little impact sparkle or clean ring effect
- satisfying sound
- brief UI animation on active player panel
- optional tiny combo feeling if multiple balls drop

WHEN THE PLAYER SCRATCHES:
- clear foul feedback
- show “Scratch” or “Cue Ball Scratch”
- visually distinguish it from normal pocketing
- different sound / warning feedback
- briefly explain turn consequence if rules support it

WHEN THE 8-BALL IS SUNK ACCIDENTALLY:
- strong event treatment
- big clear warning / fail state feedback
- examples:
  - “8-Ball Sunk”
  - “Bad Pocket”
  - “You Sunk the 8”
- dark/red dramatic overlay pulse or banner
- more intense sound cue
- transition into loss/foul logic depending on rules

WHEN IT IS A GOOD SHOT:
- stronger positive feedback
- subtle camera/table pulse or screen emphasis
- active player glow
- nicer sound stack
- ball sink should feel satisfying, not silent and dead

Keep this tasteful:
- premium arcade polish
- not cheesy casino overload
- fast and rewarding, not annoying

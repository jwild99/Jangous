The goal is to make the mobile experience feel fully built, not like a desktop layout squeezed into a phone screen.

This update must fix the following major issues:

2. Training mode still does not work correctly and needs to be repaired.

4. Every mode and screen must be reshaped properly for phone screens.

SECTION 6: MINI GOLF BOT TURN BUG

Current issue:
In Mini Golf, after the user finishes a hole, the bot keeps going and adding unlimited numbers/strokes. It does not move to the next hole. The game gets stuck on the bot turn.

Required changes:

1. Fix bot turn loop.
   The bot must stop taking shots after either:
   - The bot sinks the ball
   - The bot reaches the stroke limit
   - The bot finishes its turn
   - The hole is complete

2. Add max stroke limit per hole.
   Every hole should have a max stroke cap.
   Recommended:
   - Par 2 hole: max 6 strokes
   - Par 3 hole: max 7 strokes
   - Par 4 hole: max 8 strokes
   Or use a universal max of 8 strokes.

3. If the bot reaches max strokes, mark bot as finished for that hole.
   Do not let bot continue forever.

4. Add clear hole-complete logic.
   A hole should complete when:
   - User finished or maxed out
   AND
   - Bot finished or maxed out

5. Once both players are finished, show hole summary.
   Display:
   - User strokes
   - Bot strokes
   - Hole winner
   - Current match score
   - Button or auto-timer: âNext Holeâ

6. Auto-advance to next hole.
   After summary, move to next hole after 2 to 3 seconds or when user taps Next Hole.

7. Prevent duplicate bot timers.
   Make sure bot action timers are cleaned up.
   If using setInterval or setTimeout, clear it when:
   - Bot turn ends
   - Hole ends
   - Component unmounts
   - User exits match
   - Next hole loads

8. Bot state needed.
   Track:
   - botStrokeCount
   - botBallPosition
   - botHasFinishedHole
   - botIsTakingTurn
   - botReachedStrokeLimit

9. User state needed.
   Track:
   - userStrokeCount
   - userBallPosition
   - userHasFinishedHole
   - userReachedStrokeLimit

10. Example pseudo logic:

   function finishBotTurn() {
     if (botBallInHole || botStrokeCount >= maxStrokes) {
       setBotHasFinishedHole(true);
       setBotIsTakingTurn(false);
       checkHoleComplete();
       return;
     }

     if (!userHasFinishedHole) {
       setCurrentTurn('user');
     } else {
       runBotShot();
     }
   }

   function checkHoleComplete() {
     const userDone = userHasFinishedHole || userStrokeCount >= maxStrokes;
     const botDone = botHasFinishedHole || botStrokeCount >= maxStrokes;

     if (userDone && botDone) {
       clearBotTimers();
       setHoleComplete(true);
       showHoleSummary();
     }
   }

11. Important bot rule.
   If the user already finished the hole, the bot can continue only until it finishes or hits max strokes. It cannot go forever.

12. Reset state between holes.
   On next hole, reset:
   - userStrokeCount for hole
   - botStrokeCount for hole
   - userHasFinishedHole
   - botHasFinishedHole
   - botIsTakingTurn
   - ball positions
   - currentTurn
   - timers

13. End match after final hole.
   If Mini Golf is 3 holes, after Hole 3 show match results instead of going to Hole 4.

14. Bot score display.
   The bot score should show realistic stroke count and stop updating after bot is done.

Acceptance criteria:
- Bot does not take infinite strokes.
- Bot stops at max stroke cap.
- Hole advances after both user and bot are done.
- Hole 1 moves to Hole 2.
- Hole 2 moves to Hole 3.
- Hole 3 moves to match results.
- Refreshing or leaving the match does not leave a bot timer running.

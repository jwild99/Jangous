Allow clans to challenge other clans to wager matches.

Only clan leaders and officers can initiate challenges.

Game  
Wager amount in Scalps  
Match format  

Supported formats:

1v1  
2v2  
3v3  
5v5  

Challenge request is sent to the target clan.

Target clan leader/officer can:

Accept  
Decline  
Let it expire  

If accepted:

• match lobby is created  
• participating players are selected  
• scalps wager is locked  
• notifications sent to all players

• winning clan receives wagered scalps  
• clan stats update  
• leaderboard updates

ANTI RAGE QUIT SYSTEM

Implement a reconnect system.

If a player disconnects during a match:

• start a 5 minute reconnect timer

During the timer:

• player may reconnect and resume match  
• match state must be preserved  

If the player does not return in 5 minutes:

• match is automatically forfeited  
• opponent receives the wagered scalps  
• disconnecting player receives a loss  
• reputation penalty applied  

MATCH STATE STORAGE

Game state must save:

• score  
• turn state  
• timers  
• player positions  
• wager status  

When reconnecting:

• restore match exactly where it left off  

UI DURING DISCONNECT

Opponent sees:

Opponent disconnected  
Reconnect timer countdown  

Disconnected player sees:

Reconnect to Match button

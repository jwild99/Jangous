GLOBAL REQUIREMENT
==================================================

Every game must share a consistent “Jango Game Shell.”

This means the games should not look like 15 separate mini apps.

They should all share:
- same HUD structure
- same match intro structure
- same win/loss structure
- same player panel style
- same buttons
- same sound/haptic logic
- same transition style
- same balance/scalps display behavior
- same tournament/ranked/casual indicators

But each game should have:
- unique art direction
- unique background world
- unique animations
- unique sound style
- unique victory effect
- unique gameplay visual effects

==================================================

Every game screen must include the following layout:

- Full-screen background unique to the selected game
- Layered depth, not flat
- Animated but subtle

- pulsing border

Main playable area.

The arena should:
- feel embedded into the page
- have inner glow edges
- have subtle shadow
- have polished borders
- have responsive scaling
- stay centered

Every game should include a bottom control bar.

Buttons:

E. MATCH STATUS OVERLAY

- waiting for opponent

==================================================

Do not sacrifice performance for visuals.

Rules:
- use transform and opacity animations
- avoid layout thrashing
- use lightweight particles
- cap particle count

- keep animations smooth at 60fps

- reduce background effects
- simplify mobile effects

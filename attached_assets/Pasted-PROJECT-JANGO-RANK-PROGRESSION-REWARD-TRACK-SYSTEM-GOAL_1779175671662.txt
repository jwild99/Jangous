PROJECT: JANGO RANK PROGRESSION + REWARD TRACK SYSTEM

GOAL:
Create a dedicated rank progression page/section similar in feeling to Rainbow Six Siege’s ranked progression, where users can clearly see:

- current rank
- next rank
- progress toward next rank
- previous rank history
- rewards/items unlocked at each rank
- future rewards they can grind toward

This should make ranking up feel valuable, visual, and exciting.

==================================================

==================================================

Add access from:

==================================================
10. RANK UP REWARD FLOW
==================================================

When user reaches a new rank:

Backend:
- verifies rank change
- checks reward table
- grants reward if not already granted
- writes inventory record
- emits reward_unlocked event

Frontend:
- shows rank up modal
- shows reward reveal
- offers:
  “Equip Now”
  “View Inventory”
  “Keep Playing”

Important:
Reward unlocks must be backend-driven.
Frontend should not grant items by itself.

==================================================
12. BACKEND LOGIC
==================================================

On ranked match result:

1. Calculate rating change
2. Update user_rank_stats
3. Detect rank change
4. Check rank_rewards table
5. Grant new rewards
6. Add rank_history row
7. Emit websocket events:
   - rank_updated
   - reward_unlocked
   - inventory_updated

Rating and rewards must never be controlled by frontend.

==================================================
13. UI EVENTS
==================================================

Frontend listens for:

rank_updated:
- update progress bar
- update rank badge
- animate change

reward_unlocked:
- show reward reveal modal
- add item to inventory

inventory_updated:
- refresh cosmetics

==================================================
15. VISUAL STYLE
==================================================

This page should feel premium and game-like.

Use:
- dark background
- rank-colored glows
- animated emblems
- glass cards
- polished reward track
- subtle particles
- smooth transitions

Do NOT make it look like:
- basic settings page
- spreadsheet
- plain progress bar

It should feel like a ranked progression screen from a serious competitive game.

==================================================
18. FINAL EXPECTATION
==================================================

Users should clearly understand:
- where they are ranked
- how close they are to the next rank
- what they unlock next
- what they already earned
- why they should keep playing

This should create a grind loop:
Play ranked → gain rating → rank up → unlock item → equip item → show it off → keep playing.

The goal is to make ranking feel meaningful, visual, and rewarding without giving away free Scalps.

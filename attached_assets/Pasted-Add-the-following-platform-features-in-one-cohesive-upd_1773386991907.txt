Add the following platform features in one cohesive update: Rank / Skill Rating System, Daily & Weekly Challenges, Better Game Discovery, Notification System, Achievements & Badges, and full User Profile Pages.

Main goal:
Make the platform feel much more competitive, social, rewarding, and polished. These systems should work together and feel like one connected product ecosystem, not separate add-ons.

The final experience should increase:
- player identity
- competition
- retention
- discoverability
- engagement
- progression

==================================================
1. RANK / SKILL RATING SYSTEM
==================================================

Add a full Rank and Skill Rating system across the platform.

Use an ELO-style rating system.

Each player should have:
- Skill Rating (numeric)
- Rank Tier
- Rank Badge

Suggested starting rating:
1200

Rating should update after matches based on:
- win/loss
- opponent rating
- game type

Create these rank tiers:

- Bronze
- Silver
- Gold
- Platinum
- Diamond
- Champion

Suggested rating ranges:
- Bronze: 0–999
- Silver: 1000–1199
- Gold: 1200–1399
- Platinum: 1400–1599
- Diamond: 1600–1799
- Champion: 1800+

Each tier should have:
- its own badge
- distinct color styling
- premium visual treatment

Show rank in:
- leaderboard
- user profiles
- chat
- game lobbies
- match result screens
- friend lists

After each match, show:
- win/loss result
- rating change (+12 / -9 style)
- updated rating
- rank promotion if applicable

Add a small promotion animation if a player ranks up.

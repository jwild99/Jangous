1. DAILY CHALLENGES SECTION
==================================================

Add a clear Daily Challenges section to the dashboard.

This section should show:
- 3 to 5 active daily challenges
- challenge title
- short description
- XP reward
- progress bar
- status

Example daily challenges:
- Win 3 matches → +150 XP
- Play 5 games → +100 XP
- Win 1 ranked match → +200 XP
- Beat a higher-ranked player → +250 XP
- Join a tournament → +100 XP

Challenge states:
- In Progress
- Complete — Ready to Claim
- Claimed

When a challenge is completed:
- show a Claim button
- let the user manually press Claim
- award XP
- animate the XP gain
- play a clean reward sound
- update level progression

Add a small indicator on the dashboard if multiple challenges are ready to claim:
- “2 Rewards Ready to Claim”

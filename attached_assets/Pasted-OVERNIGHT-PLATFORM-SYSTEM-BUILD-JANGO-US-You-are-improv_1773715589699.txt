OVERNIGHT PLATFORM SYSTEM BUILD
JANGO.US

You are improving the Jango.us platform by implementing major systems that transform the site from a simple collection of games into a full competitive gaming platform similar to GamePigeon, Skillz, and modern multiplayer gaming hubs.

Your task is to build and integrate the following systems while maintaining compatibility with existing games and user accounts.

Do NOT remove existing functionality. Only extend and improve the system.

--------------------------------------------------

1. MATCHMAKING SYSTEM

Create a real matchmaking system that allows players to find opponents quickly.

Features to implement:

• Global matchmaking queue
• Skill-based matching (use player rank or win rate)
• Match found animation
• Queue timer
• Cancel queue button
• Rematch option after matches
• Private match codes for inviting friends

Flow:

Player presses "Find Match"
→ Player enters matchmaking queue
→ System searches for opponent
→ Match found screen appears
→ Game loads automatically

UI Elements:

Find Match  
Searching for Opponent…  
Opponent Found  
Rematch  
Exit Match  

Make sure matchmaking works across all multiplayer games.

--------------------------------------------------

2. SPECTATOR MODE

Allow users to watch matches live.

Features:

• Spectate button on live matches
• Live viewer count
• Real-time game rendering
• Ability to leave spectating anytime

Add a “Live Matches” section showing games currently being played.

Example:

Air Hockey Match  
Beau vs Carson  
Spectators: 7  
[Watch]

Spectators should not affect gameplay performance.

3. GAME REPLAY SYSTEM

Features:

• Replay playback controls

Replays should be accessible on the player's profile under:

5. PLAYER REPUTATION SYSTEM

Create a sportsmanship score system to encourage fair play.

Each player receives a Reputation Score.

Score increases when players:

• finish matches
• avoid reports
• maintain good behavior

Score decreases when players:

• rage quit
• disconnect frequently
• receive reports

Display on player profile:

⭐ Reputation: 92

Players with extremely low reputation may receive matchmaking penalties.

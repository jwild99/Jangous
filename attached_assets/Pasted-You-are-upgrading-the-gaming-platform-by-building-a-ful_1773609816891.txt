You are upgrading the gaming platform by building a fully functional Cosmetic Item Shop for the website. The shop must feel modern, fun, and similar in quality to major gaming platforms.

The shop must be cosmetic-only. No items may affect gameplay or give competitive advantages.

The system must work perfectly on mobile and desktop.

----------------------------

ITEM SHOP STRUCTURE

Create a new tab called Item Shop in the main navigation.

The shop should include the following sections:

• Featured Items  
• Daily Deals  
• New Releases  
• Player Cosmetics  
• Profile Cosmetics  
• Game Cosmetics  
• Emotes & Animations

Each section should show items in clean card-style grids.

Each item card must include:

• Item image or animated preview  
• Item name  
• Short description  
• Price  
• Buy button  
• Preview button

Hover (desktop) or tap (mobile) should show a live preview animation.

----------------------------

CURRENCY SYSTEM

Create a virtual currency called Coins.

Coins can be purchased using:

• Apple Pay  
• Visa / Mastercard  
• Venmo  
• Crypto (Bitcoin, ETH, SOL)

When users buy coins:

• play a cash register / cha-ching sound
• show a coin animation
• show a "Coins Added!" celebration popup

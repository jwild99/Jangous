Update all games on the platform so they are polished, intuitive, visually detailed, and aligned with modern industry standards for casual competitive web games, while also matching the premium design language of the JANGO website.

Main goal:
Make every game easier to understand, easier to start, smoother to play, more visually polished, and more consistent across the platform.

Important:
I want each game to use familiar mechanics and interaction patterns that players already recognize from other successful versions of these games.
Do not reinvent core gameplay unnecessarily.
Use standard, proven game rules and controls so users can jump in quickly with little confusion.

At the same time, update the visual design of every game so it feels fresh, immersive, detailed, and fully consistent with the overall JANGO design system.

==================================================
1. CORE GAMEPLAY STANDARDIZATION
==================================================

For each game:
- Review whether the current controls are intuitive
- Review whether the rules are clear
- Review whether the game loop is fast and understandable
- Remove confusing or unnecessary custom mechanics unless they truly improve the experience
- Keep each game aligned with what users already expect from that game

Use familiar gameplay patterns from popular casual/mobile/browser versions of each game.

Examples:
- Chess should use standard chess rules, legal move highlighting, captured piece tracking, turn indication, and clean board interaction
- Mini Golf should use familiar aim + drag/power shot controls with predictable ball physics
- Connect 4 should use classic vertical token-drop gameplay with clean turn feedback
- Air Hockey should use simple mouse/touch paddle movement with responsive puck physics
- Rock Paper Scissors should use instant selection with clear countdown and result reveal
- Dots & Boxes should use easy line placement and obvious square completion feedback
- 8-Ball Pool should use standard cue aim, power control, ball collision, and turn feedback
- Bowling should use familiar lane aim + power + curve/spin interaction if included
- Cup Pong should use simple arc-based aiming and power timing
- Tron should use clean movement, responsive turns, and readable trails
- Tower Stack should use familiar timing/drop mechanics with clear precision feedback

==================================================
2. CONSISTENT ONBOARDING
==================================================

For every game, add a simple and consistent onboarding system:

- short one-line game summary
- “How to Play” button or tooltip
- quick rules modal or expandable instructions
- controls explanation before match starts
- optional first-time tutorial overlay

Keep instructions short and easy to scan.

Example format:
- Objective
- Controls
- Win condition
- Special rules

Do not overwhelm the user with text.

==================================================
3. CONSISTENT PRE-GAME EXPERIENCE
==================================================

Before a match starts, standardize the game entry experience across all games:

Each game should include:
- game title
- short description
- difficulty or pace label if useful
- estimated match time
- play button
- practice / casual / ranked options if those exist
- simple rules link

This should feel consistent across every game.

==================================================

==================================================
20. FINAL GOAL
==================================================

The final result should be:
- easy to learn
- hard to master
- familiar to players
- polished in execution
- consistent across the platform
- visually fresh and detailed
- fully aligned with the JANGO website design system

Do not overcomplicate the games.
Use proven, recognizable mechanics and interaction patterns so players can jump in instantly and enjoy the experience.

Do not reinvent the core rules of these games. Prioritize familiar mechanics, clean controls, and polished execution over novelty.

For each game, benchmark the UX against the simplest and most popular digital version of that game type, then bring our implementation up to that level of clarity, playability, and visual quality.

Make every game feel like a premium, streamlined version of a game users already basically know how to play.

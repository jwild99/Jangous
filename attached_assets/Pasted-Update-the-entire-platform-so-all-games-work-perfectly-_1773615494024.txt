Main goals:
1. Every game must run smoothly and correctly on both desktop and mobile.

PART 1 — Desktop + Mobile Optimization

1. Responsive Layout
- All games and UI components must automatically adapt to different screen sizes.
- Support phones, tablets, laptops, and large desktop monitors.
- Prevent UI overlap, cut-off elements, or tiny unreadable text.
- Game boards, score areas, timers, and buttons must scale properly.

2. Mobile Gameplay
- Every game must have a true mobile experience, not just a scaled-down desktop version.
- Implement proper touch controls (tap, swipe, drag).
- Remove hover interactions and replace them with tap behavior.
- Increase button and control sizes for touch accuracy.
- Make sure users never need to zoom in to play.

3. Desktop Gameplay
- Ensure mouse and keyboard interactions work correctly.
- Use available screen space intelligently without stretching the interface.
- Menus, lobbies, and game controls should feel clean and easy to navigate.

4. Gameplay Testing
- Test every game individually.
- Fix broken controls, laggy movement, frozen screens, and misaligned UI.
- Ensure users can start, play, pause, restart, and finish games on all devices.

5. Performance
- Optimize games for fast load times.
- Reduce unnecessary scripts or heavy animations.
- Ensure smooth gameplay on lower-powered phones.
- Avoid frame drops and lag.

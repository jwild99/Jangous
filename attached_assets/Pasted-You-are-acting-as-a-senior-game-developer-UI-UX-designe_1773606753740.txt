MOBILE AND DESKTOP OPTIMIZATION

Every game and UI element must be optimized for both mobile and desktop.

Mobile requirements:

• Touch controls must be responsive and natural  
• Buttons must be large enough for thumbs  
• No small UI elements that are hard to tap  
• Layout must adapt to portrait and landscape  
• Controls must be thumb-friendly  
• No hover-only mechanics  
• Gameplay areas must scale to screen size  
• UI must never overlap gameplay  

Desktop requirements:

• Mouse controls must feel precise  
• Keyboard shortcuts should be added where useful  
• Larger screen layouts should take advantage of space  
• UI must scale properly on large monitors  
• Gameplay should feel responsive with mouse input  

Use responsive techniques such as:

• flexible layouts  
• scalable game canvases  
• responsive breakpoints  
• adaptive UI components  
• dynamic resizing
